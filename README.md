# FCA Enforcement Tracker

A free tracker of DOJ False Claims Act settlements for cybersecurity failures by federal contractors. Every case individually sourced.

**Live tool:** https://nehemiah313.github.io/fca-tracker/

## What it does

- **15 announced settlements, 2022 to 2026**, each with company, amount, date, what happened, the lesson, and a source link
- **Running total** computed from the dataset itself: $67,543,150 across the tracked cases
- Search, filter by year, sort by date or settlement size
- CSV export of the full dataset
- "Why this matters" explainer: treble damages, qui tam whistleblowers, SPRS scores as evidence, self-disclosure credit, successor liability

## Honest framing

This tracker lists announced settlements with individual sources. It is not exhaustive, and settlement figures are not admissions of liability unless noted. The list grows as DOJ announces new matters. Informational only, not legal advice.
